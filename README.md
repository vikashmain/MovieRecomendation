#  Movie Recommender System

A **Content-Based Movie Recommender System** built using **Python**, **Machine Learning**, and **Streamlit**. It recommends movies similar to the one selected by the user based on genres, cast, crew, keywords, and movie overview.

## Features

- 🎥 Recommend Top 5 similar movies
- 🖼️ Display movie posters using the OMDb API
- 🔍 Search movies from a dropdown
- ⚡ Fast recommendations using Cosine Similarity
- 💻 Interactive Streamlit web application

##  Tech Stack

- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
- Requests
- OMDb API

##  Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/Movie-Recommender-System.git
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Add your OMDb API key in `app.py`.

4. Run the application
   ```bash
   streamlit run app.py
   ```

##  Dataset

The project uses the ** 5000 Movies Dataset from Kaggle ** for generating recommendations.
